# HEALTHGUARD 🏫💧

## Smart School Health & Environment Analysis System

HealthGuard is a Python-based Data Science project designed to analyze classroom health and environmental conditions.

It evaluates:

- 🌡️ Classroom temperature
- 💧 Student water intake
- 🔊 Classroom noise
- ⚠️ Overall health risk

## Features

### 1. Health Risk Detection
The system calculates a risk score using temperature, hydration and noise levels.

### 2. Classroom Environment Analysis
It identifies whether the classroom environment is safe, moderate or high risk.

### 3. Data Science Analysis
HealthGuard analyzes a dataset and calculates:

- Average temperature
- Average water intake
- Average noise level
- Average risk score

### 4. Key Insights
The system identifies important patterns such as:

- Low water intake can be associated with higher risk.
- High classroom temperature can increase concern.
- High classroom noise can affect the learning environment.
- Combined environmental factors can increase overall risk.

## Technology Used

- Python
- Data Analysis
- Conditional Logic
- Statistical Averages
- Dataset-based Risk Analysis

## Project Goal

The goal of HealthGuard is to provide a simple data-driven system that can help schools identify potentially unhealthy classroom conditions and take preventive action.
